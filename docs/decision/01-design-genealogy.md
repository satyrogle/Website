# Phase 1 — Design genealogy and failure ledger

Adjudication artifact, 2026-08-12. Paper only. Scope per founder instruction:
THE CORRECTION is the candidate being worked up; the other four remain on the
shelf, unscored. Sources: repo docs, memory of the build history, and the
master brief's genealogy sections — checked against each other, with the repo
winning where they disagree.

Format per candidate: proposition / implemented? / evidence produced? /
failure reason / what it left behind.

---

## 1. Central entity (crown, halo, shards — "Crowned Convergence" lineage)

- **Proposition:** one divine central object whose comprehension turns menacing.
- **Implemented:** yes, heavily — roughly a week, 501 MB of rejected geometry
  (`references/models-archive/`), many bake/capture rounds. The current `src/`
  hero is this lineage's last state (v06, partial corrections, superseded).
- **Evidence:** real 3060 captures, repeatedly judged.
- **Failure (proven, both directions):** seeded-random placement cannot produce
  *designed* coherence. High variance read as debris; near-regular read as a
  flower/rosette. Coherence is a per-element design decision, and no parameter
  interpolates between the two failure modes. Every escape (image-to-3D,
  procedural shell, hand arrangement) relocated the problem.
- **Left behind:** `safePow` NaN lesson (ANGLE/D3D11 vs SwiftShader);
  behind-camera cull discipline; time-boxed (not step-count) warm-up; the
  capture-and-measure verification culture; palette semantics.

## 2. Signal Horizon terrain

- **Proposition:** a noise terrain has no silhouette to invent — kill the
  placement problem by having no object.
- **Implemented:** partially (branch name survives as the current branch name).
- **Failure (one line, decisive):** ground cannot loom. Orientation is a form
  property too.
- **Left behind:** the insight that removing the object does not remove the
  need for *presence*.

## 3. Trench / strata / truss

- **Proposition:** descend past strata; a truss stage carries the causal argument.
- **Implemented:** paper + partial staging.
- **Failure:** no turn — one cold register start to finish. And the truss read
  as "bridge": the moment a stage is nameable as a mundane object, the
  demonstrate-first law dies at the first glance.
- **Left behind:** the causal back half (anchors, sparse observation,
  reconstruction) — which survived into INTAKE unchanged.

## 4. Tunnel / ring class (spoke mandala, octagon, additive tunnel)

- **Proposition:** travel through a structure toward comprehension.
- **Implemented:** several times, captured.
- **Failure:** rotational symmetry. Cylindrical parameterisation reads as
  mandala / octagon / turbine / portal regardless of intent.
- **Left behind:** the hard rule now in CLAUDE.md: zero cylindrical
  parameterisation; any capture frame reading as concentric rings fails.

## 5. False Façade / Anamorphic Threshold Guardian

- **Proposition:** fixed architecture that aligns into an incomplete guardian
  silhouette at one authored viewpoint.
- **Implemented:** never. Retired as candidate without a build.
- **Failure:** never falsified — retired by supersession. Structurally it
  reintroduced authored-form dependence (the alignment IS a silhouette bet),
  the exact class that killed the entity. **Permanently rejected; do not revive**
  (master brief §29, repo CLAUDE.md).
- **Left behind:** the line "the structure did not change; your model of it
  did" — the purest statement of comprehension-menace this project has.

## 6. THE LATTICE / excess-order ascent

- **Proposition:** octet-truss recursion of one platonic form; menace is excess
  order; the turn is a Gray–Scott bifurcation — parameter glides, behaviour snaps.
- **Implemented:** never. Retired by supersession the same day it was specced.
- **Failure:** not falsified. Died administratively, not empirically.
- **Left behind (live principles, both feed CORRECTION):**
  1. **The turn is a rule change** — same system, same rule, behaviour crosses
     a threshold with hysteresis. Nothing is added; that is the menace.
  2. **The light law** — structure visible only where computation illuminates
     it. No material gloss, no fixture lighting; break it and the object is
     furniture again.

## 7. THE INTAKE

- **Proposition:** vertical descent into a grown system; the divine amber face
  is the system's record of itself; at the floor it writes you down, wrong.
- **Implemented:** never. Locked 2026-08-11, founder-vetoed the same day
  ("not landing at all").
- **Failure:** taste, at Level 0 — before any evidence existed. Its own spec
  named the growth bake as the art risk and priced the kill test at "build a
  bake pipeline first," which is the most expensive first test of any candidate.
- **Left behind:** the entire concept-independent back half, carried forward
  into every candidate: cyan/amber/violet grammar; sparse observation buffer;
  mechanism-vs-catalogue divergence; the false first action; YOUR RECORD;
  localStorage-only persistence; the honest skip path; the editorial handoff;
  demonstrate-first law.

## Failure-hypothesis test (master brief §38)

> Hypothesis: failed directions failed primarily as authored **forms**; the
> systemic argument survived.

**Verdict on this ledger: TRUE, with one amendment.** Entity died of form
coherence. Terrain died of form orientation. Trench died of register and a
nameable form. Tunnels died of form symmetry. The argument passed through all
four untouched. Amendment: INTAKE died of *founder taste at paper level* —
which the hypothesis does not cover, and which no rubric prevents. The only
defence against that failure mode is cheap early visual evidence, which is
exactly what the Level-0 evidence cap and the one-capture kill test exist for.

Per §38, concepts whose core value is testable as **event / state / relation /
constraint / propagation** before form production earn a real advantage.
THE CORRECTION is constraint + propagation by definition.

## Threat map: which dead failure classes could recur in THE CORRECTION

| Dead class | Recurrence vector | Guard |
|---|---|---|
| Entity (authored coherence) | the disciplined structure acquires a designed silhouette | structure is a rule-generated / seeded irregular graph; the hero is the *behaviour*, and the concept must survive on a schematic stage (rubric: system over form) |
| Tunnel (rotational symmetry) | radially symmetric standing modes; ring-shaped eigenmodes on a symmetric graph | irregular graph topology is **load-bearing**, not aesthetic; concentric-ring capture rule stays in force |
| Trench (no turn) | enforcement uniformly visible from frame one — nothing to comprehend | enforcement gain is spatially graded; somewhere deviation visibly survives longer, so the calm regions are *late-understood* as won territory |
| Trench (nameable object) | graph reads as "net", "web", "circuit board" | cold-review blind read asks "what do you see?" — a mundane noun at first glance is a finding |
| Taste: subtle = invisible | corrections as gentle eased drift | corrections are hysteretic, monochrome-loud *events*: parameter glides, behaviour snaps (inherited from THE LATTICE) |
| CORRECTION's own native risk | reads as snap / glitch / quantize demo / magnetic grid / physics toy | the entire §58 mitigation set: delta-driven motion only, strain phase before correction, material response not UI response, violet scarcity — this is what the kill test exists to judge |

The last row is the honest one: CORRECTION's dominant risk is not any dead
class returning. It is its own — that computed enforcement reads as animation.
That is the single uncertainty the kill test must exercise.

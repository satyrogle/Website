## Verdict protocol

- **LOCK** — approve the current gate. Later gates cannot alter it unless Jacob explicitly reopens it.
- **ADJUST** — make one controlled correction within the current gate, then recapture for review.
- **NOPE** — remove the current gate's work and return to the last locked state.
- **STOP** — end the gate workflow without starting another change.

A design lock does not authorize a Git commit, tag, push, deployment, or Meshy credit spend.

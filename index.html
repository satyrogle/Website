Desk42

A bureaucracy that remembers.

You work a desk inside a bureaucracy and decide people’s claims. A ruling made early can return later as a notice, an appeal, a changed queue or a new rule. The game keeps what happened separate from what was written down.

Every later consequence must be traceable to an earlier decision.

  • Unity
  • Windows PC
  • Bounded causal slice

Brawler

A battlefield that reacts.

Brawler is built around a deterministic reactive field. The field is not decoration. It changes movement, exposure, hazards and attacks, so changing the room changes the fight.

You change the environment. The environment changes the fight.

  • Unreal Engine
  • In development
  • No published benchmarks

What carries forward

Rules and behaviour

Tests and acceptance

The checks that define correct behaviour can remain useful even when the implementation changes.

Production knowledge

What failed, what players understood, how long the work took and how to ship it do not reset.

Engine-specific gameplay code is assessed separately and often rewritten.

We would rather be checked than believed.
